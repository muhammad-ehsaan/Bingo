This project is a two-player Bingo game developed using 8086 Assembly Language on the EMU8086 emulator. It is designed as a semester project to demonstrate assembly programming concepts, user interaction, and game logic implementation.

The game allows two players to compete against each other by marking numbers on their Bingo boards. The first player to complete the required pattern (row, column, or full card depending on rules) wins.
